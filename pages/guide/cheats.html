Notre protocole pour vérifier un code

  1. Indiquer la plateforme, le mode et le contexte exacts.
  2. Comparer le code et son défi aux guides indépendants, puis confirmer l’effet sur une partie retail; signaler les divergences plutôt que les masquer.
  3. Faire vérifier la séquence par une seconde source indépendante.
  4. Noter si le code bloque sauvegarde, trophées, missions ou progression, uniquement après test.
  5. Étiqueter chaque entrée « testé », « corroboré », « contesté » ou « non vérifié » et dater la modification.

Un glitch, un exploit et un code intégré ne sont pas la même chose. N’installe pas de mod menu tiers et ne saisis jamais tes identifiants Rockstar sur un site de « codes gratuits ».
